Estética-Renascentista

## 📒 Descrição

O desenho a mão é uma forma de arte que nem todos os seres humanos dominam, mas agora temos as IA generativas que podem nos ajudar a criar essas artes tão reais quanto as de um artista profissional. 
Neste projeto simples apresento uma imagem de desenho a mão gerada por Inteligência Artificial generativa.


## 🤖 Tecnologias Utilizadas
Ms Copilot,
Chat GPT e
Canva.

## 🧐 Processo de Criação
A partir da ideia de criar um desenho, utilizei o Chat GPT para criar o prompt de comando inicial, que seria utilizado em uma IA generativa de imagens.

Com o prompt já criado optei por usa-lo no MS Copilot para gerar a imagem.

Com a imagem gerada, fiz edições de filtros no Canva, bem como dei o título e a assinatura da obra de arte.

Após finalizado, fiz apenas pequenos ajustes de tamanho.


## 🚀 Resultados
Um desenho feito a mão utilizando grafite de uma esculura romana da época do renascimento.

## 💭 Reflexão (Opcional)
A chave para alcançar resultados de acordo com o esperado está nos prompts de comando, ou seja quanto mais específico e detalhado for o prompt, maior é a possibilidade de alcançar os resultados esperados.
